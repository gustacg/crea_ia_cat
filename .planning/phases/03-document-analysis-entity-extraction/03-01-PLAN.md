**Step 3: Implement crea_cat_ai/analysis.py**

Replace the stub entirely. Implementation must contain:

1. **Pydantic models** (copy from RESEARCH.md Pattern 1 section, verbatim):
   - `EntidadesProfissional(BaseModel)`: nome, titulo, crea_rnp (Optional[str]), cpf (Optional[str]), registro (Optional[str])
   - `EntidadesOrganizacao(BaseModel)`: nome, cnpj (Optional[str]), cpf (Optional[str])
   - `EntidadesEndereco(BaseModel)`: logradouro, numero, bairro, cidade, uf, cep (all Optional[str])
   - `EntidadesData(BaseModel)`: data_inicio, data_termino, data_emissao (all Optional[str])
   - `AssinanteInfo(BaseModel)`: nome (str), cargo (str), crea_rnp (Optional[str]), cpf (Optional[str]), engenheiro_habilitado (bool)
   - `AnaliseVisual(BaseModel)`: tem_timbre (bool), descricao_timbre (Optional[str]), tem_assinatura_visual (bool), assinantes (list[AssinanteInfo])
   - `ErroOrtografico(BaseModel)`: trecho (str), sugestao (str)
   - `ResultadoAnalise(BaseModel)`: numero_documento, profissional, contratante, empresa_executora, endereco_obra, datas, escopo, contrato_numero, art_referenciada, valor_contrato, visual, erros_ortograficos, confianca, observacoes

2. **Module-level OpenAI client**: `client = OpenAI(api_key=config.OPENAI_API_KEY)`

3. **normalizar_crea_rnp(valor: str | None) -> str | None**: strips all non-digit characters with `re.sub(r'\D', '', valor)`, returns None if input is None or result is empty string.

4. **_selecionar_paginas_analise(doc: DocumentoCarregado) -> list[PaginaDocumento]**: if len(doc.paginas) <= 3, return all; otherwise return [doc.paginas[0], doc.paginas[-1]].

5. **PROMPT_ANALISE_BASE**: the full prompt from RESEARCH.md Pattern 3 section. Must include:
   - "RNP e CREA sao EQUIVALENTES" rule
   - Entity extraction fields list
   - Visual analysis instructions (timbre, assinatura, assinantes list with engenheiro_habilitado)
   - Spell check instructions: "apenas para Atestados", ignore siglas/nomes proprios/termos tecnicos

6. **_construir_input_analise(doc, paginas) -> list[dict]**: builds Responses API input. Combines native text from selected pages (truncated to 6000 chars). Adds images with `"detail": "high"`. Includes doc.tipo.value in the text.

7. **analisar_documento(doc: DocumentoCarregado) -> ResultadoAnalise**: calls _selecionar_paginas_analise, _construir_input_analise, client.responses.parse(model=config.OPENAI_MODEL, instructions=PROMPT_ANALISE_BASE, input=..., text_format=ResultadoAnalise). Handles output_parsed=None fallback.

8. **analisar_pacote(pacote: PacoteDocumentos) -> dict[str, ResultadoAnalise]**: iterates art + atestado + complementares, calls analisar_documento for each, returns dict keyed by doc.tipo.value. Prints progress in pt-BR.

All imports: `from pydantic import BaseModel, Field`, `from typing import Optional`, `from openai import OpenAI`, `import re`, `import config`, `from crea_cat_ai.ingestion import DocumentoCarregado, PaginaDocumento, TipoDocumento, PacoteDocumentos`.

All print statements in Portuguese (pt-BR).
