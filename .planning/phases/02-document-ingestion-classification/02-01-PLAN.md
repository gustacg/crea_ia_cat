**Data structures (exact definitions):**

```python
class TipoDocumento(str, Enum):
    ART = "ART"
    ATESTADO = "Atestado"
    DECLARACAO = "Declaracao"
    ANUENCIA = "Anuencia"
    NF = "NF"
    CONTRATO = "Contrato"
    RELATORIO_FOTOGRAFICO = "RelatorioFotografico"
    DESCONHECIDO = "Desconhecido"

@dataclass
class PaginaDocumento:
    numero: int          # 1-indexed
    texto_nativo: str    # page.get_text() — empty string if scanned
    imagem_b64: str      # base64-encoded PNG

@dataclass
class DocumentoCarregado:
    caminho: Path
    tipo: TipoDocumento
    paginas: list[PaginaDocumento]
    tem_texto_nativo: bool  # True if any page has >100 chars

@dataclass
class PacoteDocumentos:
    art: DocumentoCarregado | None
    atestado: DocumentoCarregado | None
    complementares: list[DocumentoCarregado] = field(default_factory=list)
    nao_classificados: list[DocumentoCarregado] = field(default_factory=list)

class ResultadoClassificacao(BaseModel):
    tipo: str
    confianca: float
    justificativa: str
```

**OpenAI client (module-level):**
```python
client = OpenAI(api_key=config.OPENAI_API_KEY)
```

**PROMPT_CLASSIFICACAO** — use the exact prompt from RESEARCH.md Pattern 2 (lines 187-199). Include all 8 document types with descriptions in Portuguese.

**Functions:**

1. `carregar_pdf(caminho: Path) -> list[PaginaDocumento]`:
   - Open with `pymupdf.open(str(caminho))` using context manager (`with`)
   - Scale: `config.IMAGE_DPI / 72` for Matrix
   - For each page: `page.get_text()` for text, `page.get_pixmap(matrix=mat)` then `pix.tobytes("png")` then `base64.b64encode().decode("utf-8")` for image
   - Respect `config.MAX_PAGES_PER_PDF` — stop after limit
   - Return list of PaginaDocumento (1-indexed)

2. `classificar_documento(doc: DocumentoCarregado) -> ResultadoClassificacao`:
   - Use first page only (page index 0) — sufficient for classification
   - Build input with `"type": "input_text"` (first 2000 chars of texto_nativo) and `"type": "input_image"` with `"image_url": f"data:image/png;base64,{imagem_b64}"` and `"detail": "low"`
   - Call `client.responses.parse(model=config.OPENAI_MODEL, instructions=PROMPT_CLASSIFICACAO, input=[...], text_format=ResultadoClassificacao)`
   - Handle `response.output_parsed is None` (refusal) — return `ResultadoClassificacao(tipo="Desconhecido", confianca=0.0, justificativa="Modelo recusou classificação")`
   - If text is empty/whitespace, send "(sem texto nativo — documento escaneado)" as text

3. `_agrupar_documentos(documentos: list[DocumentoCarregado]) -> PacoteDocumentos`:
   - `art`: first doc where tipo == TipoDocumento.ART (use `next(..., None)`)
   - `atestado`: first doc where tipo == TipoDocumento.ATESTADO
   - `complementares`: list of docs where tipo in (DECLARACAO, ANUENCIA, NF, CONTRATO, RELATORIO_FOTOGRAFICO)
   - `nao_classificados`: list of docs where tipo == DESCONHECIDO

4. `carregar_pacote(diretorio: Path) -> PacoteDocumentos`:
   - `sorted(diretorio.glob("*.pdf"))` — raise `ValueError(f"Nenhum PDF encontrado em: {diretorio}")` if empty
   - For each PDF: print status in pt-BR, call `carregar_pdf`, determine `tem_texto_nativo` (any page with >100 stripped chars), create `DocumentoCarregado` with `DESCONHECIDO` type, call `classificar_documento`, update `doc.tipo` from result
   - Print classification result with confidence percentage
   - Return `_agrupar_documentos(documentos)`

All print messages in Portuguese (pt-BR). All paths via pathlib.Path.
