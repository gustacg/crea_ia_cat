    ```python
    class MetadadosPDF:
        creator: Optional[str] = None
        producer: Optional[str] = None
        author: Optional[str] = None
        creation_date: Optional[datetime] = None
        mod_date: Optional[datetime] = None

    ```

    **_parse_pdf_date(date_str: str) -> Optional[datetime]:**
    - Strip "D:" prefix
    - Normalize timezone: `-03'00'` -> `-0300`, `Z` -> `+0000`
    - Try formats: `%Y%m%d%H%M%S%z`, `%Y%m%d%H%M%S`
    - Return None on empty/unparseable input

    **extrair_metadados(caminho_pdf: Path) -> MetadadosPDF:**
    - `pikepdf.open(caminho_pdf)` as context manager
    - Read `pdf.docinfo` with `.get("/Creator", "")` etc.
    - ALWAYS wrap with `str()` before using (pikepdf returns pikepdf.String objects)
    - Parse dates with `_parse_pdf_date()`

    **detectar_anomalias(m: MetadadosPDF) -> list[str]:**
    - Check `config.SOFTWARE_SUSPEITO` against `m.creator` and `m.producer` (case-insensitive `in`)
    - Check `m.mod_date < m.creation_date` when both present
    - Return list of anomaly strings in Portuguese

    **processar_documento(caminho_pdf: Path) -> MetadadosPDF:**
    - Calls `extrair_metadados()`, then `detectar_anomalias()`, sets `m.anomalias` and returns
    - This is the public entry point for main.py
