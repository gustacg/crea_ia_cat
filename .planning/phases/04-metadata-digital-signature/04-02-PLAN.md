    **Constants:**
    ```python
    GOVBR_CHAIN_URL = "http://repo.iti.br/docs/Cadeia_GovBr-der.p7b"
    GOVBR_CHAIN_CACHE = config.PROJECT_ROOT / "certs" / "govbr-chain.p7b"
    ```

    **ResultadoAssinatura dataclass:**
    ```python
    @dataclass
    class ResultadoAssinatura:
        presente: bool
        quantidade: int = 0
        signatarios: list[dict] = field(default_factory=list)
    ```
    NOTE: No `anomalias` field. Absence is `presente=False, quantidade=0` — clean state per SIGN-03.

    **_carregar_govbr_chain() -> tuple[list, list]:**
    - Check `GOVBR_CHAIN_CACHE.exists()` — if not, create parent dir and download from `GOVBR_CHAIN_URL` with `urllib.request.urlopen(url, timeout=15)`
    - Parse P7B with `asn1_cms.ContentInfo.load(data)` -> `signed_data["certificates"]`
    - Separate root certs (subject == issuer) from intermediates
    - Return `(root_certs, other_certs)` as asn1crypto Certificate objects
    - On download failure: print warning in pt-BR, return `([], [])` — pipeline continues with `confiavel=False`

    **validar_assinaturas(caminho_pdf: Path) -> ResultadoAssinatura:**
    - Load Gov-Br chain via `_carregar_govbr_chain()`
    - Open PDF with `PdfFileReader(f, strict=False)` — CRITICAL: strict=False for hybrid-reference PDFs
    - Get `reader.embedded_regular_signatures`
    - If no sigs: return `ResultadoAssinatura(presente=False)`
    - For each sig:
      - Extract `sig.signer_cert` -> nome, emissor
      - Create `ValidationContext(trust_roots=root_certs, other_certs=other_certs, allow_fetching=False, moment=sig.self_reported_timestamp, revocation_mode="soft-fail")`
      - Call `validation.validate_pdf_signature(sig, signer_validation_context=vc, key_usage_settings=KeyUsageConstraints(key_usage={"digital_signature"}))`
      - CRITICAL: `key_usage={"digital_signature"}` not default (which requires non_repudiation that Gov-Br certs lack)
      - CRITICAL: `moment=sig.self_reported_timestamp` to handle expired certs valid at signing time
      - On exception: capture in `entry["erro"]`
    - Return `ResultadoAssinatura(presente=True, quantidade=len(sigs), signatarios=[...])`

    All print/log messages in pt-BR. Use `pathlib.Path` for all paths.
